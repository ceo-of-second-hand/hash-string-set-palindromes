# Множина рядків на хешуванні + пошук паліндромів

Лабораторна робота з прикладних алгоритмів (Лекція 3, варіант 2).

Структура даних «множина рядків» (1..15 рядкових латинських літер) з операціями
`+` (додати), `-` (вилучити), `?` (перевірити). Після `#` програма виводить усі
паліндроми, що є в множині. Аналіз складності та заміри часу: [REPORT.md](REPORT.md).

## Файли

| Файл | Призначення |
|---|---|
| `string_set.h` | хеш-таблиця з ланцюгами + подвійний поліноміальний хеш |
| `main.cpp` | програма лабораторної: читає операції, виводить `yes`/`no` і паліндроми |
| `brute.cpp` | еталон для перевірки (`std::unordered_set`) |
| `gen.cpp` | генератор тестів |
| `run_tests.py` | збірка + усі тести + таблиця часу |
| `tests/cases/` | ручні тести (`.in` — вхід, `.ans` — очікуваний вихід) |

## Збірка та запуск

```
g++ -O2 -std=c++17 main.cpp -o lab.exe
lab.exe input.txt            # або: lab.exe < input.txt
lab.exe -t input.txt out.txt # -t: час обробки у stderr
```

Формат входу:
```
+ abba
+ abc
? abba
- abba
? abba
#
```
Вихід:
```
yes
no
palindromes: 0
```

## Генератор тестів

```
gen N seed [add del ask] [pool] [pal]
gen 100000 42                    # 50/20/30 % операцій, пул N/3 слів, 10 % паліндромів
gen 100000 42 20 0 80 50000 0    # переважно запити, без паліндромів
```

## Тести

```
python run_tests.py          # ручні тести + випадкові N = 10^3..10^6
python run_tests.py --quick  # до 10^5
```

Кожен випадковий тест порівнює вихід `lab` з `brute` побайтово, для двох різних
основ хешу `p`. Таблиця часу пишеться в `tests/out/timings.md`.

## VS Code

- **Ctrl+Shift+B** — debug-збірка `build/lab_debug.exe`
- **F5** — налагодження на вибраному тесті з `tests/cases/`
- *Terminal → Run Task → run tests* — тести
